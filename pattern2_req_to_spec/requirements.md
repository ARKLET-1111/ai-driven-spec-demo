# 要件（numlib）

組込み制御ソフト向けの小さな数値処理ライブラリを C（C99）で作りたい。

- 提供する機能は2つ
  1. 32bit 整数配列を昇順に並べ替える（バブルソート。同じ値の順序は変えない）
  2. 連立一次方程式 Ax = b を掃き出し法（部分ピボット選択あり）で解く。n は最大 16
- 動的メモリ確保は禁止。標準入出力も使わない。依存ヘッダは stddef.h / stdint.h のみ
- エラーは戻り値で返す（0 成功、負の値で失敗）。NULL や不正な n でクラッシュしない
- 掃き出し法はピボットの絶対値が 1e-12 未満なら「特異行列」として失敗させる
- スレッドセーフは不要
- 単体試験でカバレッジ 90% 以上を取りたいので、試験観点も仕様書に含めてほしい
