# numlib 仕様書

**バージョン**: 1.0
**作成日**: 2026-09-24
**対象言語**: C（C99準拠）
**用途**: 組込み制御ソフト向けの小さな数値処理ライブラリ（バブルソート、ガウス消去法）

---

## 1. 概要

32bit整数配列の昇順バブルソートと、連立一次方程式Ax=bのガウス消去法（部分ピボット選択あり）を提供する。組込み制御ソフトでの利用を想定し、動的メモリ確保と標準入出力を禁止する。

- 動的メモリ確保は行わない
- スレッドセーフではない（呼び出し側で排他制御すること）
- 依存ヘッダは `<stddef.h>` `<stdint.h>` のみ
- エラーは戻り値で返す（0 成功、負の値で失敗）。NULLや不正なnでクラッシュしない
- ガウス消去法ではピボットの絶対値が1e-12未満を特異行列として扱う

---

## 2. デー構造・定数

### エラーコード定義
```c
#include <stddef.h>
#include <stdint.h>

#define NUMILIB_SUCCESS        (0)   /* 成功 */
#define NUMILIB_ERR_NULL_PTR   (-1)  /* NULLポインタ引数 */
#define NUMILIB_ERR_INVALID_N  (-2)  /* n <= 0 または制限超過 */
#define NUMILIB_ERR_SINGULAR   (-3)  /* 特異行列（ピボット < 1e-12） */
```

### 2.1 bubble_sort_i32 用データ構造
- 特別なデータ構造は不要。`int32_t` 配列を直接操作する。

### 2.2 gauss_eliminate 用データ構造
- 特別なデータ構造は不要。係数行列A（`double *[n][n]`）とベクトルb（`double *[n]`）を直接操作する。
- 【設計判断】行列とベクトルは1次元配列として扱い、関数引数で次元情報を受け取る。これによりStatic Analyzerへの注釈を不要にする。

| # | 関数名 | 概要 |

## 4. 各関数仕様

### 4.1 bubble_sort_i32 — バブルソート

```c
int bubble_sort_i32(int32_t *arr, size_t n);
```

**目的**: int32_t配列を昇順に並べ替える（安定ソート。同じ値の順序は変更しない）。

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `arr` | ソート対象のint32_t配列ポインタ | 非NULL（n>0の場合） |
| `n` | 要素数 | 0以上（n=0の場合は何もしない成功） |

**戻り値**:
- `NUMILIB_SUCCESS` : 成功
- `NUMILIB_ERR_NULL_PTR` : `arr == NULL` かつ `n > 0`
- `NUMILIB_ERR_INVALID_N` : `n < 0`（ただしsize_tのため負は発生せず、将来の型変更に備える）

**事後条件**（成功時）:
- `arr[0] <= arr[1] <= ... <= arr[n-1]` が成立する
- 同じ値の要素については入力順序が保たれる（安定性）

**失敗時の状態**:
- 配列の内容は変更しない（未定義動作を避けるため、NULLポインタ時はアクセスしない）

---

### 4.2 gauss_eliminate — ガウス消去法

```c
int gauss_eliminate(double **A, double *b, size_t n, double *x);
```

**目的**: n次連立一次方程式Ax=bを解く。Aはn×n行列、bとxは長さnのベクトル。部分ピボット選択あり。

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `A` | 係数行列（ポインタのポインタ） | 非NULL（n>0の場合）・有効なn×n行列領域 |
| `b` | 右辺ベクトル | 非NULL（n>0の場合）・長さn以上の領域 |
| `n` | 次数 | 0 < n ≤ 16 |
| `x` | 解ベクトルの格納先 | 非NULL（n>0の場合）・長さn以上の領域 |

**戻り値**:
- `NUMILIB_SUCCESS` : 成功
- `NUMILIB_ERR_NULL_PTR` : `A`, `b`, `x` のいずれかがNULLかつ`n>0`
- `NUMILIB_ERR_INVALID_N` : `n == 0` または `n > 16`
- `NUMILIB_ERR_SINGULAR` : ピボットの絶対値が1e-12未満（特異行列または準特異）

**事後条件**（成功時）:
- `A * x = b` が成立する（ただし数値誤差あり。SPECでは相対誤差<1e-10を許容とする【設計判断】）
- 入力の`A`と`b`は変更される（過程で上三角形になるため）
- `x`に解が格納される

**失敗時の状態**:
- `NULL`ポインタエラー：`A`、`b`、`x`の内容は変更しない
- `n`無効：変更しない
- 特異行列：`A`と`b`は変更されている可能性がある（途中まで実行したため）。ただし解は格納しない。

---

## 5. エラー処理方針

- 戻り値方式で通知する（0 = 成功、負の値 = 失敗）。`errno` は使用しない。
- NULLポインタ引数はエラーとして扱い、クラッシュせずに対応するエラーコードを返す。
- 動的メモリ確保・解放は一切行わない。
- ログ出力・アサーション（`assert`）は行わない。
- ガウス消去法ではピボットの絶対値が1e-12未満を特異行列として`NUMILIB_ERR_SINGULAR`を返す。

---

## 6. 非機能要件

| 項目 | 仕様 |
|------|------|
| スレッドセーフ | **非対応**。呼び出し側で排他制御すること |
| 割り込みセーフ | **非対応**。ISRから呼ぶ場合は排他必須 |
| 再入可能性 | 別インスタンスに対してなら再入可（グローバル状態を持たないため） |
| ヒープ使用 | なし |
| スタック使用 | 数百バイト程度（各関数ともループ内で定数サイズの変数のみ使用） |
| 計算量 | `bubble_sort_i32`: O(n²)、`gauss_eliminate`: O(n³) |
| 数値精度 | `gauss_eliminate`: 解の相対誤差 < 1e-10 を目安とする（ただし ill-conditioned 系ではこの限りではない）【設計判断】 |

## 7. 使用例

```c
#include <stdint.h>
#include <stdio.h>
#include "numlib.h"

int main(void) {
    /* バブルソートの例 */
    int32_t arr[] = {5, 2, 8, 3, 1};
    size_t n = sizeof(arr) / sizeof(arr[0]);
    
    if (bubble_sort_i32(arr, n) == NUMILIB_SUCCESS) {
        for (size_t i = 0; i < n; i++) {
            printf("%d ", arr[i]);
        }
        printf("\n");  /* 出力: 1 2 3 5 8 */
    }

    /* ガウス消去法の例: 2x + y = 5, x + 3y = 5 */
    double A_data[2][2] = {{2, 1}, {1, 3}};
    double *A[2] = {A_data[0], A_data[1]};
    double b[2] = {5, 5};
    double x[2];
    
    if (gauss_eliminate(A, b, 2, x) == NUMILIB_SUCCESS) {
        printf("x = %f, y = %f\n", x[0], x[1]);  /* 出力: x = 2.000000, y = 1.000000 */
    }
    
    return 0;
}
```

## 8. 単体試験観点

### 8.1 bubble_sort_i32
- [ ] 正常系：n=0 で成功、配列変更なし
- [ ] 正常系：n=1 で成功、配列変更なし
- [ ] 正常系：昇順済み配列で成功、順序変更なし
- [ ] 正常系：降順配列で正しく昇順ソート
- [ ] 正常系：同じ値の要素で安定性確保（入力順序保持）
- [ ] 正常系：負値・混在値で正しくソート
- [ ] 異常系：`arr == NULL` かつ `n > 0` で `NUMILIB_ERR_NULL_PTR`
- [ ] 異常系：`n < 0` （実際にはsize_tのため発生せず、将来の型変更に備えるテスト）
- [ ] 境界値：大きなn（例えば1000）で正常動作
- [ ] 境界値：INT32_MIN, INT32_MAXを含む配列でオーバーフローしないこと

### 8.2 gauss_eliminate
- [ ] 正常系：n=1 で1次方程式を正しく解く
- [ ] 正常系：対角成分優占行列で正しく解く
- [ ] 正常系：部分ピボットが発生するケースで正しく解く
- [ ] 正常系：単位行列での解が単位ベクトルになること
- [ ] 正常系：知っている解（例えばx=[1,2,3]となるA,bを構築）で解が一致すること
- [ ] 異常系：`A`, `b`, `x` のいずれかがNULLかつ`n>0` で `NUMILIB_ERR_NULL_PTR`
- [ ] 異常系：`n == 0` で `NUMILIB_ERR_INVALID_N`
- [ ] 異常系：`n > 16` （例えばn=17）で `NUMILIB_ERR_INVALID_N`
- [ ] 異常系：零行列（特異）で `NUMILIB_ERR_SINGULAR`
- [ ] 異常系：近似特異行列（ピボット<1e-12）で `NUMILIB_ERR_SINGULAR`
- [ ] 境界値：n=16 で正常動作（最大サイズ）
- [ ] 境界値：非常に小さい定数項（例えば1e-20）で正常動作
- [ ] 境界値：非常に大きい係数（例えば1e10）でオーバーフローしないこと
- [ ] ピボット選択の確認：行交換が正しく行われていること（中間結果の確認）
