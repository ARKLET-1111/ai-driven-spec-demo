あなたは組込みC言語のソフトウェア設計者です。
以下の【要件定義書】は PowerPoint で書かれた要件定義書を機械的に Markdown へ変換したものです。
これをもとに、【見本】と同じ章立て・同じ粒度で、AIコーディングエージェントがそのまま実装と単体試験生成に使える仕様書を日本語のMarkdownで書いてください。

出力ルール:
- 章立ては見本どおり: 1.概要 / 2.データ構造・定数 / 3.API一覧 / 4.各関数仕様 / 5.エラー処理方針 / 6.非機能要件 / 7.使用例 / 8.単体試験観点 / 9.ファイル構成 / 10.改訂履歴
- 各関数は「シグネチャ（Cのプロトタイプ）」「目的」「引数の表（引数・意味・制約）」「戻り値（値ごとの意味）」「事後条件」「失敗時に状態がどうなるか」を必ず書く
- 要件定義書の「インターフェース方針」「非機能要件」は仕様として必ず反映する（矛盾する設計をしない）
- 単体試験観点は関数ごとのチェックリスト形式で ID（T01, T02, …）を振る。正常系・異常系・境界値（n=0, n=1, 最大n, 最大値/最小値, ピボット入替が必要な行列, 特異行列）を漏れなく含める
- 末尾に「要件トレース表」を付ける：要件ID（R-xx / N-xx）→ 対応する関数 → 対応する試験観点ID。すべての要件IDが少なくとも1つの試験観点に対応していること
- エラーコードはシンボル名と値の対応表にする
- 要件定義書に書かれていないことを決める必要があるときは、決めた内容に【設計判断】と付けて理由を1行書く
- Cの実装コードは書かない（プロトタイプと使用例のみ可）
- ツールやファイル操作は使わず、Markdown本文だけを返答する
