# numlib ライブラリ仕様書

**バージョン**: 1.0  
**作成日**: 2026-09-25  
**対象言語**: C（C99準拠）  
**用途**: 組込み制御ソフトにおける整列と連立一次方程式の求解を提供する共通ライブラリ  

---

## 1. 概要

numlib は、組込み制御ソフトで共通して使用される「整列」および「連立一次方程式の求解」機能を提供するライブラリである。ヒープメモリを使用せず、スタックまたは静的領域のみで動作し、シングルスレッド環境での使用を前提とする。関数はエラーを戻り値で通知し、NULL ポインタや不正なパラメータでもクラッシュしない。

- 動的メモリ確保は行わない（スタットic・スタックのみ）
- スレッドセーフではない（呼び出し側で排他制御すること）
- 依存ヘッダは `<stddef.h>` `<stdint.h>` のみ
- 行列は行優先（row-major）の 1 次元配列 `double[n*n]` で渡す
- 整列対象は 32bit 符号付き整数 (`int32_t`) の配列

---

## 2. データ構造・定数

```c
#include <stddef.h>
#include <stdint.h>

/* エラーコード */
#define NUMLIB_SUCCESS            (0)   /* 成功 */
#define NUMLIB_ERR_NULL_PTR      (-1)   /* NULL ポインタ引数 */
#define NUMLIB_ERR_INVALID_SIZE  (-2)   /* サイズ超過（ソルバーでは n>16）または不正な長さ */
#define NUMLIB_ERR_SINGULAR_MATRIX (-3) /* 特異行列（ピボットの絶対値が 1e-12 未満） */

/* 特異行列判定の閾値 */
#define NUMLIB_PIVOT_THRESHOLD (1e-12)
```

### 設計上の要点

- エラーコードは負の値とし、0 を成功とする。
- 特異行列判定の閾値は要求仕様 R-06 に基づき `1e-12` と設定した。（【設計判断】求解精度 R-07 とのバランスを考慮）
- ソルバーでは入力行列 A とベクトル b を作業領域として破壊する（インターフェース方針に準拠）。
- 整列関数は安定ソートを実装するため、挿入ソートを採用する。（【設計判断】安定性 R-01 と計算量 O(n²) 以内 N-04 を満たすため）

## 3. API 一覧

| # | 関数名 | 概要 |
|---|--------|------|
| 1 | `numlib_sort` | int32_t 配列の昇順整列（安定） |
| 2 | `numlib_solve` | 連立一次方程式 Ax = b の解求出（n ≦ 16、部分ピボット選択実施） |

---

## 4. 各関数仕様

### 4.1 `numlib_sort` — int32_t 配列の昇順整列（安定）

```c
int numlib_sort(int32_t *arr, size_t n);
```

**目的**: int32_t 要素の配列を昇順に整列する。同じ値の相対順序を保つ安定ソートである。

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `arr` | 整列対象の配列へのポインタ | `n > 0` の場合は非NULL、`n == 0` では NULL でも可（何もしない） |
| `n`   | 要素数 | 0 以上（制限なし。ただしスタック使用量は定数） |

**戻り値**:
- `NUMLIB_SUCCESS` : 成功
- `NUMLIB_ERR_NULL_PTR` : `arr == NULL` かつ `n > 0`

**事後条件**（成功時）:
- `arr[0] <= arr[1] <= ... <= arr[n-1]` が成立する
- 同じ値の要素については入力時の相対順序が保たれる（安定性）
- `n == 0` または `n == 1` の場合は配列内容を変更しない

**失敗時の状態**:
- 配列内容は変更しない（`arr` の参照先は不変）

---

### 4.2 `numlib_solve` — 連立一次方程式 Ax = b の解求出

```c
int numlib_solve(double *A, double *b, double *x, size_t n);
```

**目的**: n × n 実数行列 A と長さ n の実数ベクトル b に対して、連立一次方程式 Ax = b を解き、解ベクトル x を求める。n ≦ 16 を前提とし、部分ピボット選択による LU 分解を実施する。

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `A`  | 行列要素を格納した配列（行優先、長さ n*n） | 非NULL、`n > 0` の場合は少なくとも `n*n` 要素確保済み |
| `b`  | 右辺ベクトルを格納した配列（長さ n） | 非NULL、`n > 0` の場合は少なくとも `n` 要素確保済み |
| `x`  | 解ベクトルを格納する配列（長さ n） | 非NULL、`n > 0` の場合は少なくとも `n` 要素確保済み |
| `n`  | 行列の次数 | 0 ≦ n ≦ 16 |

**戻り値**:
- `NUMLIB_SUCCESS` : 成功
- `NUMLIB_ERR_NULL_PTR` : `A == NULL` または `b == NULL` または `x == NULL` （`n > 0` 時）
- `NUMLIB_ERR_INVALID_SIZE` : `n > 16`
- `NUMLIB_ERR_SINGULAR_MATRIX` : ピボットの絶対値が `NUMLIB_PIVOT_THRESHOLD` 未満の特異行列を検出

**事後条件**（成功時）:
- `A * x ≈ b` が成立する（ここで `A` は入力行列、`x` は出力解ベクトル）
- `n == 0` の場合は何もしない（`x` も変更しない）
- `n == 1` の場合は `x[0] = b[0] / A[0]` が成立する
- 入力行列 A とベクトル b は破壊される（作業領域として使用したため）

**失敗時の状態**:
- 出力ベクトル `x` の内容は保証しない
- 入力行列 A とベクトル b は変更しない（特異行列検出時は作業に入らないため）
- `n > 16` または NULL ポインタの場合は入力変更なし

---

## 5. エラー処理方針

- エラーは戻り値で通知する（0 = 成功、負の値 = 失敗）。`errno` は使用しない。
- NULL ポインタ引数はエラーとして扱い、クラッシュせずに対応するエラーコードを返す。
- 動的メモリ確保・解放は一切行わない。
- ログ出力・アサーション（`assert`）は行わない。
- 特異行列検出時は解を書き込まない（要求仕様 R-06）。

### エラーコード一覧

| エラーコード | 値 | 意味 |
|--------------|----|------|
| `NUMLIB_SUCCESS` | 0 | 成功 |
| `NUMLIB_ERR_NULL_PTR` | -1 | NULL ポインタ引数 |
| `NUMLIB_ERR_INVALID_SIZE` | -2 | サイズ超過（ソルバーでは n>16）または不正な長さ |
| `NUMLIB_ERR_SINGULAR_MATRIX` | -3 | 特異行列（ピボットの絶対値が 1e-12 未満） |

---

## 6. 非機能要件

| 項目 | 仕様 |
|------|------|
| 動的メモリ確保 | 行わない（スタック・静的領域のみ） |
| 標準入出力 | 製品コードでは使用しない（試験コードは可） |
| コンパイル警告 | `-Wall -Wextra -Wpedantic` で警告ゼロ（C99） |
| 計算量 | 整列：O(n²) 以内、求解：O(n³) 以内 |
| スタック使用量 | n ≦ 16 を前提とした定数以内（再帰禁止） |
| スレッドセーフ | 不対応（呼び出し側で排他制御すること） |

## 7. 使用例

### 7.1 整列の使用例

```c
#include "numlib.h"
#include <stdio.h>

int main(void) {
    int32_t data[] = {5, 2, 8, 1, 9};
    size_t n = sizeof(data) / sizeof(data[0]);

    if (numlib_sort(data, n) == NUMLIB_SUCCESS) {
        for (size_t i = 0; i < n; ++i) {
            printf("%d ", data[i]);
        }
        // 出力: 1 2 5 8 9
    }
    return 0;
}
```

### 7.2 連立一次方程式の求解の使用例

```c
#include "numlib.h"
#include <stdio.h>

int main(void) {
    // 2x2 系: 2x + y = 5, x + 3y = 5
    double A[4] = {2.0, 1.0, 1.0, 3.0}; // 行優先
    double b[2] = {5.0, 5.0};
    double x[2];

    if (numlib_solve(A, b, x, 2) == NUMLIB_SUCCESS) {
        printf("x = %f, y = %f\n", x[0], x[1]);
        // 出力: x = 2.000000, y = 1.000000
    }
    return 0;
}
```

## 8. 単体試験観点

### 8.1 `numlib_sort`
- [T01] 正常系：n=0 で成功（配列変更なし）
- [T02] 正常系：n=1 で成功（配列変更なし）
- [T03] 正常系：n=5 のランダム配列を昇順に整列し、安定性を確認（同じ値の順序保持）
- [T04] 異常系：`arr == NULL` かつ `n > 0` で `NUMLIB_ERR_NULL_PTR`
- [T05] 異常系：`arr == NULL` かつ `n == 0` で `NUMLIB_SUCCESS`（何もしない）【設計判断】空配列の場合はアクセスしないため安全
- [T06] 境界値：要素がすべて同じ値の配列（安定性確認）
- [T07] 境界値：降順ソートされた配列の整列
- [T08] 境界値：昇順ソート済み配列の整列（既に整列済み）

### 8.2 `numlib_solve`
- [T09] 正常系：n=0 で成功（ベクトル変更なし）
- [T10] 正常系：n=1 で成功（`x[0] = b[0] / A[0]`）
- [T11] 正常系：n=2 の正則行列を解き、解が正しいことを確認
- [T12] 正常系：n=16 の正則行列を解き、解が正しいことを確認（最大 n）
- [T13] 正常系：ピボット選択が発生する行列（対角要素が 0 の行列）を解けること
- [T14] 異常系：`A == NULL` または `b == NULL` または `x == NULL` （`n > 0` 時）で `NUMLIB_ERR_NULL_PTR`
- [T15] 異常系：`n > 16` で `NUMLIB_ERR_INVALID_SIZE`
- [T16] 異常系：特異行列（ピボットの絶対値 < 1e-12）で `NUMLIB_ERR_SINGULAR_MATRIX` かつ `x` 未変更
- [T17] 境界値：n=16 のほぼ特異行列（ピボット値 = 1e-12）で成功すること
- [T18] 境界値：n=16 の特異行列（ピボット値 = 0）で `NUMLIB_ERR_SINGULAR_MATRIX`
- [T19] 精度確認：条件数 1e6 以下の行列で、解の相対誤差が 1e-9 以内であること（要求仕様 R-07）
- [T20] 作業領域破壊確認：入力 `A` と `b` が関数後に変更されていること
