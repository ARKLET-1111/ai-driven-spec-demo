# numlib 数値処理ライブラリ 仕様書

**バージョン**: 0.9  
**作成日**: 2026-09-25  
**対象言語**: C（C99準拠）  
**用途**: 組込み制御ソフト向けの小規模な数値処理ライブラリ  

---

## 1. 概要

組込み制御ソフト向けの小規模な数値処理ライブラリである。  
- 動的メモリ確保（malloc/free）は使用しない  
- スレッドセーフ非対応（呼び出し側で排他）  
- 依存ヘッダは `<stddef.h>` `<stdint.h>` のみ  
- 浮動小数点は `double`。`printf` 等の標準I/Oは使わない  
- 提供関数  
  - `bubble_sort_i32` … 32bit整数配列の昇順ソート（バブルソート・安定）  
  - `gauss_eliminate` … 連立一次方程式 Ax = b を掃き出し法で解く（部分ピボット選択付き）

## 4. 各関数仕様

### 4.1 `bubble_sort_i32` … 32bit整数配列の昇順ソート（安定）

```c
int bubble_sort_i32(int32_t *arr, size_t n);
```

**目的**: `arr[0..n-1]` を昇順に並べ替える。等しい値の相対順序は保つ（安定ソート）  

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `arr` | 整列対象の配列 | `n > 0` のとき非NULL であること |
| `n`   | 要素数 | 0 以上。`n <= 1` のときは何もしない |

**戻り値**:
- `0`：成功  
- `-1`：引数不正（`n > 0` かつ `arr == NULL`）  

**事後条件**（成功時）:
- すべての `i` （`0 <= i < n-1`）について `arr[i] <= arr[i+1]`  
- 要素の多重集合は入力前と不変  

**失敗時の状態**:
- 配列の中身は変更しない（不変）【要確認】  

**計算量**: 時間 O(n²)、追加メモリ O(1)。既ソート入力では 1 パスで終了する（早期終了フラグ）  

*対応単体試験観点: T01, T02, T03, T04, T05, T06*

### 4.2 `gauss_eliminate` … 連立一次方程式 Ax = b を掃き出し法で解く（部分ピボット選択付き）

```c
int gauss_eliminate(double *a, double *b, double *x, size_t n);
```

**目的**: n×n 行列 A と右辺 b から Ax = b の解 x を求める（部分ピボット選択付き掃き出し法）  
※ 行列 A は行優先（row-major）で格納  

**引数**:
| 引数 | 意味 | 制約 |
|------|------|------|
| `a`  | n×n 行列を行優先で格納した配列 | 非NULL。作業領域として破壊してよい |
| `b`  | 右辺ベクトル（長さ n） | 非NULL。作業領域として破壊してよい |
| `x`  | 解の出力先（長さ n） | 非NULL |
| `n`  | 次元 | 1 以上 16 以下（NUMLIB_MAX_DIM = 16） |

**戻り値**:
- `0`：成功  
- `-1`：引数不正（`a == NULL` または `b == NULL` または `x == NULL` または `n == 0`）  
- `-2`：特異行列（ピボット選択後の `|a[k][k]| < EPS`）  
- `-3`：`n > NUMLIB_MAX_DIM`（16 を超えた）  

**事後条件**（成功時）:
- 出力ベクトル `x` が Ax = b を満たす（条件数 1e6 以下の行列で相対誤差 1e-9 以内）  
- 入力行列 A とベクトル b は破壊される（作業領域として使用後の内容は不定）  

**失敗時の状態**:
- 引数不正時：出力ベクトル `x` の内容は保証しない【要確認】  
- 特異行列時：出力ベクトル `x` の内容は保証しない【要確認】  
- 次元超過時：出力ベクトル `x` の内容は保証しない【要確認】  

**特異判定**: ピボット選択後の `|a[k][k]| < EPS`（EPS = 1e-12）のとき特異とみなす  
**精度**: 条件数 1e6 以下の行列で相対誤差 1e-9 以内  

*対応単体試験観点: T07, T08, T09, T10, T11, T12*

## 5. エラー処理方針

- 戻り値方式で通知する（0 = 成功、-1/-2/-3 = 失敗）。`errno` は使用しない。  
- NULL ポインタ引数はエラーとして扱い、クラッシュせずにエラーコードを返す。  
- 動的メモリ確保・解放は一切行わない。  
- ログ出力・アサーション（`assert`）は行わない。  
- エラー時の出力引数（例: `x` 配列）の内容は保証しない（未定義）【要確認】

## 7. 使用例

```c
#include "numlib.h"
#include <stdio.h>
#include <stdint.h>

int main(void) {
    /* bubble_sort_i32 の使用例 */
    int32_t data[5] = {5, 2, 4, 1, 3};
    if (bubble_sort_i32(data, 5) == 0) {
        for (int i = 0; i < 5; i++) {
            printf("%d ", data[i]);  /* 出力: 1 2 3 4 5 */
        }
        printf("\n");
    }

    /* gauss_eliminate の使用例 */
    /* 2x2 連立方程式:
     * 2x +  y = 5
     *  x + 3y = 5
     * 解: x = 2, y = 1
     */
    double A[4] = {2.0, 1.0, 1.0, 3.0};  /* 行優先 */
    double b[2] = {5.0, 5.0};
    double x[2];
    if (gauss_eliminate(A, b, x, 2) == 0) {
        printf("x = %f, y = %f\n", x[0], x[1]);  /* 出力: x = 2.000000, y = 1.000000 */
    }
    return 0;
}
```
※ 使用例は仕様書に記載された振る舞いを示すものであり、実際の動作は各関数仕様に従う【要確認】
