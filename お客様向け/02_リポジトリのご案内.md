## 1. 一言で

「PowerPoint / Excel の仕様書 → AI が読める仕様書 → ローカルLLM による実装・単体試験」を、**実際に動かした入力・出力・ログをそのまま置いた**リポジトリです。読み物（`docs/`）と、証拠（`pattern1〜3/`）に分かれています。

## 2. フォルダの見方

| フォルダ・ファイル | 中身 | いつ見るか |
|---|---|---|
| `README.md` | 全体の報告書（結果・注意点・次の一手） | 最初に |
| `docs/01`（仕様書の書き方） | AI が読みやすい仕様書の章立てテンプレートと書き方のコツ | 仕様書を書く・書かせるとき |
| `docs/02`（PowerPoint / Excel → Markdown の手順） | PowerPoint / Excel → Markdown の手順、OCR エンジンの注意 | 既存資料を変換するとき |
| `docs/03`（プロンプトと実行コマンド） | 使ったプロンプトの一覧（全文は `pattern2_req_to_spec/prompts/`）、実行コマンド、つまずきやすい点 | 実際に動かすとき |
| `pattern1_legacy_to_md/` | ダミーの PPT / Excel と、その変換結果 | 変換の品質を確かめたいとき |
| `pattern2_req_to_spec/` | Nemotron が書いた仕様書（要件から／要件定義書から／既存資料から）と、商用モデルとの比較 | 生成される仕様書の品質を確かめたいとき |
| `pattern3_impl/` | 仕様書から Nemotron が実装した C コード・単体試験・カバレッジ結果・実行ログ | 「本当に動いたか」を確かめたいとき |

`_` で始まるファイル（`_prompt_sent.md`、`_run.log` など）は、実行時に送った指示文と生ログです。再現性の証跡として残していますが、通常は読む必要はありません。

## 3. まず読む3つ

1. `README.md` — 5分。結果と注意点が分かります
2. `docs/01` — 仕様書をどう書けばよいか。テンプレートはここです
3. `pattern2_req_to_spec/COMPARISON.md` — ローカルLLMと商用モデルの差がどこにあるか

## 4. 手元で試す最短手順

**前提**: Python 3.10 以上、OpenCode、Nemotron-3-Super に接続できる環境（オンプレの vLLM など）。

```bash
# ① 既存資料を Markdown に変換する（ネット接続不要・資料は外に出ません）
pip install docling
docling 仕様書.pptx --to md --image-export-mode referenced --output out/

# ② Nemotron に仕様書を書かせる（見本と章立てを添えた指示文は docs/03 参照）
opencode run --agent plan -m <プロバイダ>/<Nemotronのモデル名> "$(cat 指示文.md)" < /dev/null > 仕様書.md

# ③ 仕様書から実装・単体試験・カバレッジまで回す（pattern3_impl のルールと Makefile をそのまま使えます）
cd pattern3_impl && opencode run -m <プロバイダ>/<Nemotronのモデル名> "$(cat ../pattern2_req_to_spec/prompts/C_仕様書から実装.md)" < /dev/null
make test && make coverage      # 人が同じコマンドで結果を再確認
```

## 5. 貴社環境（オンプレ）で動かす場合に変わる点

| 項目 | 検証時（クラウド経由） | 貴社環境 |
|---|---|---|
| モデルの指定 | `openrouter/nvidia/nemotron-3-super-120b-a12b` | vLLM 上の Nemotron を指すプロバイダ名に変更（設定ファイル1か所） |
| 変換ツールの導入 | `pip install docling` | ネット接続のある PC で取得して持ち込み。画像・PDF も扱う場合は OCR モデル（EasyOCR / Tesseract）も事前取得 |
| OCR エンジン | 指定なしだと中国製（RapidOCR）が動く | **必ず `--ocr-engine` で指定**（PowerPoint / Excel の文字と表だけなら OCR は不要） |
| 所要時間 | 本資料の値 | 実機で要計測 |

指示文・ルール（`AGENTS.md`）・ビルド手順（`Makefile`）はそのまま使えます。

## 6. ご注意

- リポジトリ内の資料はすべて弊社が作成した**ダミー**です。貴社の資料・情報は含まれていません
- `opencode run` をスクリプトから呼ぶ場合は `< /dev/null` を付けてください（標準入力待ちで停止します。`docs/03` 参照）
